# 📚 Library Management System using Python OOP

A menu-driven **Library Management System** built using **Python Object-Oriented Programming (OOP)** concepts. This project demonstrates the use of classes, objects, constructors, methods, data structures, exception handling, and file handling to manage books, issue and return operations, search records, and store data permanently.

## 🚀 Features

- Add new books
- Display all books
- Search books by title
- Issue books to students
- Return issued books
- View issued book records
- Store book data using TXT file handling
- Handle invalid user inputs gracefully

## 🛠️ Concepts Used

- Python Classes and Objects
- Constructors (`__init__`)
- Object-Oriented Programming
- Functions and Methods
- Conditional Statements
- Loops
- Lists
- Dictionaries
- Sets
- Exception Handling
- File Handling
